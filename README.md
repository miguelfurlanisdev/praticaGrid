# GridLab – Demonstração Prática de CSS Grid

## Sobre o projeto

O **GridLab** é um projeto desenvolvido com o objetivo de demonstrar, na prática, o funcionamento do **CSS Grid**, uma tecnologia do CSS utilizada para criar layouts organizados em linhas e colunas.

O projeto apresenta uma página com menu lateral, área principal organizada em blocos e rodapé, demonstrando diferentes possibilidades de posicionamento e dimensionamento dos elementos.

## Objetivo

Demonstrar como o CSS Grid facilita a construção de layouts, permitindo organizar elementos de maneira estruturada, responsiva e eficiente, sem depender de posicionamentos manuais.

## Estrutura do projeto

- **Sidebar:** menu lateral com links de navegação.
- **Main:** área principal organizada com CSS Grid.
- **Caixas:** elementos que representam diferentes conteúdos, como notícias, fotos, vídeos e músicas.
- **Footer:** rodapé com informações de direitos autorais e identificação do aluno.

## Conceitos de CSS Grid apresentados

O projeto utiliza classes específicas para demonstrar diferentes comportamentos dos elementos dentro da grade:

| Classe | Função |
|---|---|
| `.grade` | Define o elemento como um container Grid. |
| `.caixa` | Define os elementos que ocupam as células da grade. |
| `.larga` | Demonstra um elemento que ocupa mais espaço na horizontal. |
| `.alta` | Demonstra um elemento que ocupa mais espaço na vertical. |
| `.primeira` | Permite destacar e posicionar um elemento específico. |
| `.toda` | Demonstra um elemento que ocupa toda a largura disponível. |

## Como funciona?

O CSS Grid trabalha com dois eixos principais:

- **Colunas (Columns):** organizam os elementos horizontalmente.
- **Linhas (Rows):** organizam os elementos verticalmente.

Com propriedades como `display: grid`, `grid-template-columns`, `grid-template-rows`, `grid-column` e `grid-row`, é possível controlar a distribuição e o posicionamento dos elementos.

## Tecnologias utilizadas

- HTML5 – estruturação da página.
- CSS3 – estilização e organização do layout com Grid.

## Conclusão

Com o desenvolvimento do GridLab, foi possível compreender melhor como funciona o CSS Grid e como ele pode ser aplicado em projetos reais.

A atividade demonstra que, utilizando linhas, colunas e posicionamentos, podemos construir layouts mais organizados, flexíveis e profissionais.
